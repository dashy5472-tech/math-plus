# 수학 역량 플러스 연습장

고등학교 2학년 미적분Ⅰ 수행평가 준비용 웹 앱입니다.
다섯 주제(상대성이론 · 세금제도 · 심전도 · 지진파 · 망각곡선) 중 하나를 골라
읽기자료를 보며 활동지의 문항을 그대로 풀어 볼 수 있습니다.

- 숫자·선택 문항은 자동 채점, 서술 문항은 자기점검 체크리스트
- 힌트는 두 단계까지, 답을 직접 알려 주지 않습니다
- 모든 문항을 풀면 「내 정리 카드」가 열리고 PDF로 저장할 수 있습니다
- 학생이 쓴 답은 그 기기에만 저장되며 어디로도 전송되지 않습니다

`index.html` 파일 하나로 동작합니다.
